# XH OS Enhanced - سیستم عامل موبایل HTML بهبود یافته

## معرفی
XH OS Enhanced یک سیستم عامل موبایل کاملاً HTML است که با طراحی مدرن شبیه One UI 8 و انیمیشن‌های جذاب ساخته شده است. این نسخه بهبود یافته شامل صفحه بوت پیشرفته، صفحه قفل بدون رمز، صفحه اصلی مدرن و ۱۶ برنامه کاربردی است.

## ویژگی‌ها

### 🚀 صفحه بوت (Boot Screen) - پیشرفته
- لوگوی XH OS با انیمیشن پرش و درخشش
- لودر حلقه‌ای با ذرات متحرک
- پس‌زمینه گرادیانی پویا با ذرات شناور
- نسخه سیستم عامل (8.0)

### 🔒 صفحه قفل (Lock Screen) - مدرن
- بدون نیاز به رمز عبور
- ساعت دیجیتال و آنالوگ همزمان
- والپیپر گرادیانی متحرک با افکت blur
- دکمه‌های دسترسی سریع (دوربین، چراغ قوه)
- راهنمای انیمیشنی "برای باز کردن به بالا بکشید"

### 🏠 صفحه اصلی (Home Screen) - One UI Style
- شبکه ۴x۴ آیکون برنامه‌ها (۱۶ برنامه)
- ویجت سلامتی در بالای صفحه
- داک شیشه‌ای شناور با ۴ برنامه اصلی
- انیمیشن‌های تعاملی پیشرفته
- نوار وضعیت مدرن با آیکون‌ها

### 📱 برنامه‌های کاربردی (۱۶ برنامه)
1. **تلفن** - شماره‌گیر HD با صفحه کلید فارسی
2. **مخاطبین** - دفترچه تلفن هوشمند با جستجو
3. **پیام‌رسان** - چت امن با رمزنگاری end-to-end
4. **اینترنت** - مرورگر سریع با حالت تاریک
5. **دوربین** - دوربین ۱۰۸MP با HDR و فلش
6. **گالری** - گالری عکس با سازماندهی هوشمند
7. **موسیقی** - پلیر پیشرفته با کنترل پخش
8. **آب و هوا** - پیش‌بینی دقیق با جزئیات
9. **ساعت** - ساعت آنالوگ و دیجیتال پیشرفته
10. **تقویم** - تقویم هوشمند با یادآوری‌ها
11. **ماشین حساب** - ماشین حساب علمی با طراحی مدرن
12. **تنظیمات** - تنظیمات پیشرفته سیستم
13. **یادداشت** - یادداشت‌برداری سریع و هوشمند
14. **نقشه** - ناوبری GPS با مسیریابی
15. **فایل‌ها** - مدیریت فایل‌ها و پوشه‌ها
16. **فروشگاه** - فروشگاه برنامه‌های XH OS

## سفارشی‌سازی پیشرفته

### تغییر پالت رنگی One UI
متغیرهای CSS در ابتدای فایل `enhanced.css`:
```css
:root {
    --primary-blue: #0066FF;     /* آبی اصلی One UI */
    --accent-purple: #8B5CF6;    /* بنفش accent */
    --accent-green: #10B981;     /* سبز accent */
    --accent-orange: #F59E0B;    /* نارنجی accent */
    --accent-pink: #EC4899;      /* صورتی accent */
}
```

### اضافه کردن برنامه جدید
1. تابع `createAppNameApp()` در `enhanced.js` اضافه کنید
2. آیکون در `index.html` با ساختار جدید تعریف کنید:
```html
<div class="app-icon" data-app="app-name">
    <div class="app-bg">
        <i class="fas fa-icon-name"></i>
    </div>
    <div class="app-name">نام برنامه</div>
</div>
```
3. در `initializeApps()` ثبت کنید
4. ویژگی‌های خاص در `initializeAppFeatures()` اضافه کنید

### تغییر والپیپر پویا
رنگ‌های گرادیان در `.wallpaper-image` را تغییر دهید:
```css
.wallpaper-image {
    background: linear-gradient(135deg, 
        #000 0%, 
        var(--primary-blue) 30%, 
        var(--accent-purple) 70%, 
        #1a1a2e 100%);
}
```

### سفارشی‌سازی انیمیشن‌ها
- **Boot Animation**: تغییر `@keyframes logoBounce`
- **Wallpaper**: تنظیم `@keyframes wallpaperShift`
- **Transitions**: سفارشی‌سازی `cubic-bezier` curves
